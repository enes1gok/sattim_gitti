# Generated application assets

Created with the built-in imagegen tool. All depicted findings are fictional samples. These assets are project-owned copies; app rendering does not depend on temporary or generated-image storage paths.

- `car-front.png`: realistic silver compact SUV, front three-quarter view, nose pointing right, black roof rails and alloy wheels; full car on a pure white studio backdrop with soft ground shadow, no UI/text/markings. Matches the selected visual reference. Consumed by the main hero and exploration sheet.
- `car-top.png`: same silver compact SUV, true overhead view, front pointing up, clear roof/windows/body panels, pure white backdrop, no UI/text/markings. Consumed by the overhead view.
- `sample-scratch.png`: authentic-looking diffuse-daylight phone photo of three fine shallow clearcoat scratches on a silver SUV door, partial black handle at upper right, no dramatic damage or text. Consumed only by the explicitly fictional example evidence sheet.

Reference: `../../qa/design-reference.png` (user-selected first generated design).

UI icons: Phosphor React, https://github.com/phosphor-icons/react. Font: locally bundled Inter Variable via Fontsource.

3D model: `models/demo-suv.glb` is a real CC0 Kenney mesh, separate from the generated raster images. See `models/README.md` for provenance and processing details.
